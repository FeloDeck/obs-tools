# Changelog

What each release brings, newest first.

## v0.1.0

_14 October 2026_

Welcome to OBS Tools for OpenDeck `v0.1.0`! All actions of BarRaider's OBS Tools, rebuilt for OpenDeck on Linux, plus the everyday OBS actions that Linux users miss.

### Highlights

- Smart scene keys with a live picture and live/preview frames
- Source animations with Record, export and import
- Instant replay on stream, in slow motion, with Twitch chat and clips
- Stream health light, dropped frames alarm and CPU usage
- Live level meters on volume keys and dials
- Dials for volume, scenes, transitions and filter values
- Source visibility, hotkeys, screenshots, media control, text, profiles
- Most keys do one thing on press, another on hold and another on double press
- Text keys that set a text, go through a list, count or run a timer
- Push to talk, and taking the preview live in studio mode
- Keys tell you why they failed, and show a yellow dot until they are set up
- In English and German, following the language of OpenDeck
- Reads port and password of the local OBS with one click
